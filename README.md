# Women Safety Alert System

## About the Project

The Women Safety Alert System is an Arduino-based project developed to help women during emergency situations. When the emergency button is pressed, the system sends the user's location to a saved contact using GPS and GSM modules. It also activates a buzzer and LED to alert nearby people.

## Features

- Emergency button for quick help
- GPS-based location tracking
- Sends emergency alert message
- Buzzer and LED indication
- Simple and easy-to-use system

## Components Used

- Arduino Uno
- GPS Module (NEO-6M)
- GSM Module (SIM800L/SIM900A)
- Push Button
- Buzzer
- LED
- Breadboard
- Jumper Wires

## Software Used

- Arduino IDE
- ThingSpeak

## How It Works

1. The system continuously monitors the emergency button.
2. When the button is pressed:
   - The GPS module collects the current location.
   - The GSM module sends an emergency message with the location.
   - The buzzer and LED are activated for alert indication.

## Project Type

Group Project

## Conclusion

This project provides a simple and affordable safety solution that helps users send emergency alerts quickly during unsafe situations.
